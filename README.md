# AI Nutrition Tracker

A single-user nutrition tracking prototype built with Next.js and Tailwind. It includes a basic login screen, a meal-entry dashboard, and goal tracking for key macro nutrients.

## Features

- Email/password login screen
- Food entry workflow
- Daily nutrient summary
- Goal sliders for calories, protein, carbs, fat, and fiber
- Responsive dashboard UI

## Local setup

1. Install dependencies:
   npm install
2. Copy environment variables:
   cp .env.example .env.local
3. Run the app:
   npm run dev
4. Open http://localhost:3000
